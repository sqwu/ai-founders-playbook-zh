## 项目背景

本项目是 Anthropic 发布的《The Founder's Playbook: Building an AI-Native Startup》的完整简体中文翻译版本。原文档探讨了 AI 如何重塑 2026 年的创业生态，为创始人提供了在 AI 原生时代构建和扩展创业公司的指南。

### 为什么翻译此文档？

- **时效性强**：文档针对 2026 年的创业环境，内容前沿且具有实践指导意义
- **专业价值高**：涵盖创业生命周期的四个核心阶段，提供具体的 AI 工具使用建议
- **中文读者需求**：帮助中文读者无障碍地获取最新的创业知识和 AI 应用洞察

---

## 翻译说明

### 翻译原则

1. **准确性**：专业术语保持一致，如 "AI-native" 译为 "AI 原生"，"MVP" 保留英文缩写并补充中文解释
2. **完整性**：完整保留原文档的所有章节和内容
3. **流畅性**：符合中文表达习惯，确保阅读体验自然
4. **文化适配**：对涉及西方文化的内容进行适当注释说明

### 术语对照表

| 英文术语 | 中文翻译 | 说明 |
|---------|---------|------|
| AI-native | AI 原生 | 指以 AI 为核心基础设施的创业模式 |
| MVP | 最小可行产品 | Minimum Viable Product |
| GTM | 上市策略 | Go-To-Market |
| PMF | 产品-市场匹配 | Product-Market Fit |
| TAM/SAM/SOM | 市场规模模型 | 总可寻址市场/可服务市场/可获得市场 |

## 排版优化

### 优化要点

1. **目录结构**：添加清晰的章节导航和锚点链接
2. **视觉层次**：使用颜色编码区分不同章节，增强可读性
3. **响应式设计**：支持桌面端和移动端访问
4. **交互体验**：添加返回顶部按钮、平滑滚动等功能
5. **代码高亮**：使用 Tailwind CSS 实现现代化样式

### 技术栈

- **框架**: 纯 HTML + CSS (Tailwind CSS 3)
- **字体**: Noto Sans SC (Google Fonts)
- **图标**: SVG inline icons
- **部署**: GitHub Pages
